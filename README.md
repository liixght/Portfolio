# Temi (Liixght) — 3D Developer Portfolio

React 19 + Vite + React Three Fiber developer portfolio. Iterative build per
`Temi_Liixght_Big_Pickle_Portfolio_Spec.json`.

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build to `dist/`
- `npm run preview` — preview the production build
- `npm run lint` — run ESLint

## Layout

- `src/components/` — 3D scene and overlay components
- `src/data/` — static project/skill/tool data (added in later iterations)
- `legacy/` — the previous vanilla HTML/CSS/JS site, kept for reference
